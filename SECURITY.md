# Security Policy

## Supported Versions

This project is currently maintained on the `main` branch.

## Reporting a Vulnerability

Please report vulnerabilities privately.

- Do not open a public GitHub issue for security vulnerabilities.
- Send details to the security contact defined by your team/process.
- Include reproduction steps, impact, and suggested remediation if available.

We aim to acknowledge reports quickly and provide regular status updates until resolution.

## Safe Disclosure Guidelines

- Do not share secrets, API keys, or personal data in reports.
- Keep proof-of-concept payloads minimal and non-destructive.
- Only test against systems and data you are authorized to assess.
